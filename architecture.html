🏗️ Architecture

How the harness is wired together.

        ┌─────────────┐      POST /chat/completions (SSE)
        │  WebView UI │ ────────────────────────────────►  ProviderAdapter
        │  (bridge)   │ ◄───────── streaming deltas ───────  (OpenAI-compatible)
        └──────┬──────┘
               │ window.OFH.send / onDelta / onDone / onTool
               ▼
          AgentLoop        plan → LLM → execute → observe → repeat
          │   │  │
          │   │  └──► ToolRegistry ──► web_search · web_fetch · device_info · memory · skills
          │   └──────► run budget (120s) + memory + skills injection
          └──────────► history / messages
ProviderAdapter — one HTTP client for every provider: streaming SSE, tool-call parsing, auth.
AgentLoop — runs a turn, executes tools, observes results, streams the reply; capped by iteration + a 120s budget.
ToolRegistry — register / dispatch tools by name with JSON schema.
ProviderConfig — presets + ~/.ofh/ persistence.

🌲 Open Forest Harness
