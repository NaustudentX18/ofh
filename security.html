🔒 Privacy & security

How your data is handled.

  • Local-first default — transcripts, preferences, history stay on-device. No account required.
  • No cloud sync — conversations are never auto-uploaded.
  • On-device API keys — in ~/.ofh/.credentials.yaml, never baked into the APK.
  • Direct connections — requests go straight to your chosen provider; no middle server.
  • Offline/local option — Ollama Local never leaves your network.

Reporting a vulnerability

See SECURITY.md. Do not open a public issue for security problems.
