Why OFH

A real agent harness, not a wrapper

OFH is built from scratch in pure Kotlin — its own agent loop, its own OpenAI-compatible client, its own tool registry, and its own chat UI. No third-party engine, no hidden server.

How it works

From prompt to answer in three steps

The agent plans, calls tools, and streams — all on your device, capped by a 120-second run budget.

You pick a provider

Setup wizard or in-chat switcher — cloud API or a local Ollama.

OFH runs the loop

Plan → act → observe. It calls tools, searches the web, reads results.

It streams the answer

Tokens appear live with tool-call cards, never a silent wait.
