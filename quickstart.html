🚀 Quickstart

Install OFH and run your first agent in a few minutes.

1 · Install the APK from Releases.
2 · Verify the download (recommended) — compare against the release's SHA256SUMS:
shasum -a 256 OFH-v0.2.0.apk
3 · First launch → the provider setup wizard appears.
4 · Pick a provider
  • Cloud (Ollama Cloud / MiniMax / Z.AI / Qwen / DeepSeek / OpenAI) → paste your API key.
  • Ollama Local → no key; base URL defaults to http://127.0.0.1:11434/v1.
  • Custom → any OpenAI-compatible base URL + model.
5 · Save and start chatting. Switch providers/models anytime from the chat header.

Zero-key smoke test

Run a local Ollama, pick Ollama Local, and ask "what's the newest iPhone and how much?" — it streams an answer and runs a real web_search tool call.
