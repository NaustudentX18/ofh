🗺️ Roadmap

Prioritized plan from a 5-agent research sweep.

Recommended build order

Phase 0 · Prove it runs

On-device smoke test vs a live provider; get CI green.

Phase 1 · Trust & reliability

Permission gates, provider fallback router, token budget, hooks.

Phase 2 · Delight

Streaming polish, voice input (STT), markdown/code, history + edit/retry.

Phase 3 · Memory

On-device vector + keyword retrieval, embeddings, conversation compression.

Phase 4 · Proactive & multi-agent

Background curator, cron, sub-agents, MCP client, gateway.

Phase 5 · Scale

More providers, multimodal, widgets, Play-store readiness.

The full prioritized backlog lives in ROADMAP.md.
