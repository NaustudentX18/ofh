Config files

OFH mirrors a clean, portable layout under ~/.ofh/:

~/.ofh/settings.yaml          # providers + agent-default-model
~/.ofh/.credentials.yaml      # API keys (never baked into the APK)

Your API key lives on-device. Requests go directly to the provider you choose — no middle server.
